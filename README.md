# JS-localStorage实战项目：Todo-List

【中文简介】

在Web使用localStorage可以在浏览器存储用户保存的数据，就算用户刷新页面或者退出浏览器也不会使数据消失，暂时代替了后端写数据库的需求。

【English brief introduction】

Using localStorage in Web can store user's data in browser,even if user refreshes the web or withdraw from the brower ,the data will never disappear automatically.It can temporarily replace the demand of **Back-end Database**.
